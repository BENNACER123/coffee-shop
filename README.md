# ☕ Coffee Shop Website

A modern and responsive coffee shop website built using HTML and CSS.

## 📌 About the Project

This project is a coffee shop landing page designed to provide a modern and attractive user experience.

The website includes sections such as:

- Hero section
- Coffee specialties
- Menu
- Desserts
- About
- Contact

## 🛠️ Technologies

- HTML5
- CSS3
- Flexbox
- CSS Grid
- Responsive Design

## 🎯 What I Learned

While building this project, I practiced:

- Creating semantic HTML structure
- Building layouts with Flexbox and CSS Grid
- Creating responsive designs
- Using CSS variables
- Adding hover effects and transitions
- Improving UI/UX

## 🚀 Future Improvements

I plan to add JavaScript features in the future, such as:

- Interactive navigation
- Menu filtering
- Shopping/cart functionality
- Dynamic interactions
